- PB 번은 투 스텝, PD 및 B번은 투 스텝 인터랙티브 문제입니다.
- 본대회 Judgehost는 AWS EC2 c8i.xlarge 인스턴스를 4개 사용하였습니다. 이 과정에서 시간 제한을 Polygon에 비해 줄였는데, Polygon에서의 TL이 다른 문제는 아래와 같으니 세팅하실 때 참고해 주세요.
  - E: 2초
  - G: 4초
  - J: 4초
- 문제별 체커는 다음과 같습니다.
  - E, F, G, M: `ncmp`
  - A: `hcmp`
  - D, PA: `yesno`
  - I, J: `lcmp`
  - L: `wcmp`
  - B, C, H, K, N, PB, PC, PD, PE: 직접 작성한 체커 `chk.cpp`
  - M번은 SJ를 사용하지 않지만 SJ를 사용하는 것처럼 보이도록 세팅하여야 합니다.
